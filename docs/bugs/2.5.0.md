# Bugs - 2.5.0

Released: not yet - `VERSION` is set to 2.5.0 and this is the list it
will ship with.
Products: gc323 2.5.0, gc301 2.5.0 (m30 0.1.0 is not shippable, see
`config/m30.h`)

## Fixed

| Issue | Severity | Models | Summary |
| ----- | -------- | ------ | ------- |
| - | minor | all | The About box showed a version that was typed into `ABOUT.CPP` by hand, so it could disagree with what was built. It now shows the model and the version the build actually used. |
| - | minor | all | The About box showed no model, so the only way to tell a GC323 build from a GC301 build was to read the source. It now shows `MODEL_CODE`. |
| - | minor | all | Copyright line still read 1999-2019. |

No entries have issue numbers because there was no issue tracker when
they were found. From 2.5.1 on, every line here has one - see
[README.md](README.md).

## Known open

## Notes

2.5.0 is a minor bump with no functional change. It marks the point where
builds became reproducible: the version and the model settings come from
`VERSION` and `config/`, both committed, so `git checkout v2.5.0` plus
`tools\build.bat gc323` reproduces the shipped EXE. A 2.4.x EXE cannot be
reproduced - the settings it was built from only ever existed in one
person's working copy of `INTERNAL.H`.

Before shipping: build gc323 and gc301, and confirm the About box reads
the right model and `2.5.0` on each.
