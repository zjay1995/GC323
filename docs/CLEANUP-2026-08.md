# Cleanup, August 2026

What was removed from the tree, why, and how to get any of it back.

The repository held `gc323-2026-08-07.zip` (5.3 MB) plus a partial
extraction of the same snapshot in `gc323-2026-08-07/`, plus a stray
`WPEAK.EXE` at the root. The zip contained 314 files, 19 MB. `src/` now
holds 204 files, 2.9 MB - every source, header, resource, bitmap, icon
and help file that the build needs, and nothing else.

**Nothing was lost.** Everything listed below is in git history. The zip
is at commit `321c309`:

```
git show 321c309:gc323-2026-08-07.zip > snapshot.zip
```

Every removed file was byte-identical to its copy in that zip - checked
before deleting. `src/ACQUIRE.CPP` and `src/TCTRL.CPP` were also verified
identical to the two copies that had been extracted into the repository.

## Kept, and why it might look like it should not have been

- `WINSTUB.EXE` - not build output. It is the DOS stub the linker embeds;
  `WPEAK.DEF` names it. `.gitignore` has an exception for it.
- `WPEAK.HLP` - build output in principle, but it is produced by `hc31`
  and we cannot currently prove that tool still exists anywhere. Kept
  until someone rebuilds it from `HELP.rtf` and `WPEAK501.HPJ`.
- `WPEAK.INI` - carries the column and sample flow calibration constants,
  which are not in any source file.
- `BRADSHAW.JOB`, `BRADSHAW.run`, `BRADSHAW.wnd` - a real job, run list
  and window layout. The only sample data in the tree.
- `PID_v1.cpp/.h`, `SimpleKalmanFilter.cpp/.h` - not in `WPEAK.PRJ` and
  not included anywhere, but they are complete, self-contained modules
  added in 2020-2021 rather than scratch. Left alone. Delete them if they
  were an experiment that ended.
- `WPEAKC.CPP/.DEF/.PRJ/.RC` - a second, smaller project. Still builds.
- `CBW_ERR.RC`, `COMMERR.RC`, `cbw.h`, `Daqx.h`, `Di2s32.h`, `45XDLL.H`,
  `SeaIo32.h`, `JSB63xDll.h`, `Hdrdef32.h`, `thermo.h` - vendor SDK
  headers. Build inputs.
- All 60-odd `.bmp`/`.ico` files - resources referenced by `WPEAK.RC`.
